# 深渊银行 · 敲击提款机

一台可以敲的虚拟提款机。敲一下吐一点「深渊信用点」（A-CRED），连续敲击叠 COMBO，还有暴击。

## 玩法

- 点击机器任意位置，或按空格键敲击
- 每敲一次随机获得 3～11+ 点虚拟信用点，从出钞口喷出来
- 连续敲击会累积 COMBO，COMBO 越高暴击率越高（最高 30%）
- 暴击时一次性吐出 8～14 倍，满屏金色钞票、震屏、闪光、冲击波和 CRITICAL 大字
- 余额保存在 localStorage，刷新不丢；右上角可关音效，屏幕右上角 RESET 清零

## 说明

- 货币单位是 `◈` / `A-CRED`，纯虚拟信用点，不对应任何国家货币，也不能兑换
- 纯静态单文件，无外部依赖、无图片、无 CDN，微信内可直接打开
- 音效由 WebAudio 实时合成，没有音频文件
