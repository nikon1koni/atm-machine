# 猫猫银行 · 敲敲提款机

一台软乎乎的猫猫提款机。敲一下掉「小鱼干」，连续敲击叠 COMBO，还有猫猫暴击和满屏小鱼干雨。

## 玩法

- 点击机器任意位置，或按空格键敲击
- 每敲一次随机获得 4～12+ 条小鱼干，从出钞口喷出来
- 连续敲击会累积 COMBO，COMBO 越高猫猫暴击率越高（8% → 最高 30%）
- 暴击时一次性吐出 8～14 倍，满屏小鱼干、猫爪印、毛线球、星星、彩纸、震屏、闪光、冲击波和「猫猫暴击！」大字
- 小鱼干雨会**持续叠加**：连续暴击时旧雨不会消失，新雨继续落，越连越密
- 所有小鱼干都严格从 **FISH OUT 出鱼口**喷出，再向上喷泉式散开落下
- 余额保存在 localStorage，刷新不丢；右上角可关音效，屏幕右上角 RESET 清零

## 这次更新的重点

- **改名 + 换皮**：深渊银行 → 猫猫银行，黑底霓虹 → 奶油粉彩，曲奇小脸 → 会眨眼的猫猫头
- **货币改成小鱼干**：`🐟` / FISH，纯虚拟数值，不对应任何国家货币
- **特效加量**：小鱼干、猫爪印、毛线球、星星、彩纸、鱼雨、冲击波、彩虹暴击字
- **手机端性能优化**：
  - 粒子从 DOM 元素改成单个 Canvas 粒子引擎
  - 鱼/爪印/毛线球/星星全部预渲染成精灵，每帧只做 `drawImage`
  - 手机端限制 90 个粒子、桌面 140 个，超出自动淘汰最旧的
  - 手机端 Canvas 内部分辨率降到 0.8，减少填充压力
  - 音效限频、余额存档防抖、连击动画限频，避免连续点击时堆任务
  - 实测 390×844 手机视口 + 4 倍 CPU 降速，连续 70 次点击仍约 49 FPS
